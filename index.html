Alma de Fora & Alma de Dentro

```

Duas partes de uma mesma identidade: aquilo que o mundo enxerga e aquilo que existe dentro de nós.

```
```
☀️ Alma de Fora
A imagem que aparece para todo mundo
Essa é a parte visível: o rosto, a aparência, o jeito de se apresentar e aquilo que as pessoas percebem primeiro.
🌙 Alma de Dentro
Tudo aquilo que mora aqui dentro, mesmo quando ninguém consegue enxergar.
Toque numa bolha para descobrir seu significado. Arraste para reorganizar.
```
